# TaskBoard

TaskBoard est une petite application web sans framework conçue pour servir de
support à une formation Git/GitHub. Elle permet d'ajouter, terminer et supprimer
des tâches, avec une sauvegarde dans le navigateur.

## Lancer le projet

Ouvrez simplement `index.html` dans un navigateur, ou démarrez un serveur local :

```bash
npx serve .
```

## Lancer les tests

```bash
npm test
```

## Supports de formation

- `PARCOURS_GIT.md` explique les notions et le parcours complet ;
- `COMMANDES_DEMO_GIT.md` contient les commandes PowerShell prêtes à exécuter
  pendant une démonstration.
